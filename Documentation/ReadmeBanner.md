# README banner

[Readme-Banner.png](Images/Readme-Banner.png) is new promotional artwork for this
restoration, generated with the built-in image-generation tool on 29 October
2026. It is documentation artwork; game textures and the original executable
remain unchanged. The original game identity remains attributable to its creators.

The visual references were `Icon Composer/SpaceUndeadbeef.icon/Assets/TitleSky.png`
and `Ship.png`, whose own reconstruction provenance is recorded in
[AppIcon.md](AppIcon.md). This banner is not recovered high-resolution game art.

Keep the ship's recognizable silhouette and simple armor. Typography on the left should honor the game's original spare title: large orange 'SPACE' above large warm-white 'DEADBEEF', a fine white underline. Below it, smaller clear text exactly 'Restored for modern Apple platforms'. A restrained small '1.1' version badge near the title. No additional logos, buttons, UI mockups, decorative ships or menus. Elegant, faithful to the provided game identity, with generous margins and readable typography at README width. This is a brand-new promotional documentation banner, not a replacement for in-game artwork.

The final PNG was inspected at README width for title spelling, margins,
contrast and ship placement.
