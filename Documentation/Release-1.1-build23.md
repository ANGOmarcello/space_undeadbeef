# Space Deadbeef 1.1 (23)

The restored game runs on modern iPhone and iPad using its original game
logic, with Retina artwork, responsive controls, and local progress saves.
This build adds optional iCloud Drive progress sharing through **Options → iCloud
Progress**. Choose the same dedicated folder on each device; incoming progress
appears at the title screen.

## Downloads

- **SpaceDeadbeef.ipa** — unsigned ARM64 device build for iOS/iPadOS 18 or later.
  Sign it with your own account and sideload it using a tool such as
  [Sideloadly](https://sideloadly.io/).
- **SpaceDeadbeef-source.zip** — matching Xcode project, prepared game resources,
  restoration source, build instructions and notices.
- **SHA256SUMS** — checksums for both downloads.

The IPA is for iPhone and iPad. Mac, Apple TV and Watch use their own Xcode
schemes in the source archive. For local packaging and checking the artifacts,
see [BUILDING.md](../BUILDING.md). For folder setup and progress behavior, see
[iCloud progress](ICLOUD.md).

Original game content retains its ownership. See the [notices](../THIRD_PARTY_NOTICES.md).
